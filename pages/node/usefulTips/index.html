# EventEmitter

const { EventEmitter } = require("events");
const emitter = new EventEmitter();

emitter.on("doSomething", (arg1, arg2) => {
  console.log(`${arg1} ${arg2}`);
});

emitter.emit("doSomething", "Hello", "World"); // 'Hello World'

# ReferenceError: __dirname is not defined

原因，NodeJS 支持通过 ESM 方式导入模块 package.json 加了以下配置

"type": "module",

使用下面的替代

import { fileURLToPath } from "url";
import { dirname } from "path";
const __filename = fileURLToPath(import.meta.url);
const __dirname = dirname(__filename);
console.log(__filename);
console.log(__dirname);

# node 服务心跳机制

‌Node 服务部署心跳请求的核心原因 ‌ 心跳机制是分布式系统与长连接场景中的关键设计，Node 服务部署心跳请求主要基于以下核心需求：

‌ 一、维持长连接活跃性 ‌ ‌ 防止网络设备中断连接 ‌

在 TCP 长连接中，若长时间无数据传输，路由器、防火墙等中间设备可能主动关闭连接。通过 ‌ 周期性发送心跳包 ‌（如 WebSocket 中的 PING/PONG），可告知网络设备连接仍在使用，避免被误判为闲置 。 ‌ 规避 NAT 超时问题 ‌

在 NAT 网络环境下，客户端与服务端的映射表项会因超时被删除。心跳包可刷新 NAT 映射，维持连接可路由性。 ‌ 二、实时检测连接与节点状态 ‌ ‌ 快速发现异常断连 ‌

若客户端或服务端因网络波动、进程崩溃等原因断连，心跳机制通过 ‌ 超时未响应 ‌（如 Node.js WebSocket 服务设定 1 秒超时）可快速触发重连或容错处理。 ‌ 分布式系统的节点健康监控 ‌

在微服务架构中（如 Nacos 注册中心），Node 服务通过心跳向中心上报存活状态。若中心未收到心跳，则判定节点故障并剔除，避免请求路由至不可用节点。 ‌ 三、资源管理与负载均衡优化 ‌ ‌ 释放无效连接资源 ‌

Node 服务需管理大量并发连接。通过心跳检测“僵尸连接”（如客户端异常退出未主动关闭），可及时释放 Socket、内存等资源，防止泄漏。 ‌ 动态调整服务负载 ‌

心跳包可携带节点负载信息（如 CPU、内存使用率），供负载均衡器决策。例如 Hadoop 的 NodeManager 通过心跳向 ResourceManager 上报资源状态，实现任务调度优化。 ‌ 四、容错与高可用保障 ‌ ‌ 自动重连机制 ‌

心跳检测到断连后，Node 服务可自动触发重连逻辑（如 WebSocket 客户端重连），减少人工干预，提升系统鲁棒性。 ‌ 故障转移与冗余备份 ‌

在集群部署中，若主节点心跳丢失，备用节点可快速接管服务，避免单点故障导致服务中断

WebSocket 服务端心跳示例

const WebSocket = require("ws");
const wss = new WebSocket.Server({ port: 8080 });

wss.on("connection", (ws) => {
  // 定时发送心跳包
  const heartbeatInterval = setInterval(() => {
    if (ws.readyState === WebSocket.OPEN) {
      ws.ping(); // 发送 PING 帧
    }
  }, 30000); // 30 秒一次

  // 监听 PONG 响应
  ws.on("pong", () => {
    ws.isAlive = true; // 标记连接活跃
  });

  // 检测超时
  const checkAlive = setInterval(() => {
    if (!ws.isAlive) {
      ws.terminate(); // 超时未响应则关闭连接
      clearInterval(heartbeatInterval);
      clearInterval(checkAlive);
    }
    ws.isAlive = false; // 重置状态等待下一次 PONG
  }, 45000); // 超时设为 45 秒（略大于心跳间隔）
});

my-Skill/
├── Skill.md          # 必需：核心指令
├── rules/            # 可选：规则设置
│   └── crud.md
├── examples/         # 可选：输入/输出示例
│   ├── input.md
│   └── output.md
├── templates/        # 可选：可复用的模板
│   └── component.tsx
├── LICENSE.txt       # 可选：开源协议
└── resources/        # 可选：参考文件、运行脚本或素材
    └── style-guide.md

# uipro-cli

UI-UX-Pro-Max-Skill 就是为了解决这个问题而生的。它不仅仅是一个代码库，更是给 AI 装上的一个专业设计大脑。它包含 67+ UI 风格、96+ 行业配色 和 100+ 推理规则，让 AI 能够像资深设计师一样思考。

# 1. 全局安装工具
npm install -g uipro-cli
# 2. 为你的 AI 助手注入灵魂 (按需选择)
uipro init --ai claude      # Claude Code 用户
uipro init --ai trae        # Trae 用户
uipro init --ai cursor      # Cursor 用户
uipro init --ai windsurf    # Windsurf 用户

# skill-creator

帮你创建自己的自定义技能。不想学开发标准？直接对 Claude 说帮我做一个什么功能的 Skill，它自动帮你写好。

# planning-with-files

这是 Manus 式持久化 Markdown 规划模式的实现，解决了 Claude 原生规划模式容易失忆的问题。规划文档会保存到本地文件，即使对话中断也能继续。

# superpowers

是指一套为 Claude Code 等 AI 编码代理设计的完整软件开发工作流系统，包含 20 多个可组合技能，覆盖需求梳理、架构设计、测试驱动开发、代码审查等全流程。它通过结构化的工程流程（需求澄清 → 设计 → 计划 → 实现 → 审查）约束 AI 行为，避免直接生成偏离目标的代码，强调先明确需求再执行开发，确保代码质量和可维护性

# ralph-wiggum

是指一种基于 AI 的编程思想和方法论，核心是通过无限循环反复向 AI 编码 Agent 输入提示语，不断迭代修改代码直至满足要求

# 类型合并&的特性

  • 若某属性在至少一个类型中为必选 ‌，则合并后为必选属性 ‌
  • 基础类型冲突时（如 number vs string），合并为 never。

# TS 结构类型系统

function logName(obj: { name: string }) {}
logName({ name: "Alice", age: 25 }); // ❌ 报错
// ‌通过变量传递时‌，TypeScript 会允许子类型（结构兼容性生效）
const obj = { name: "Alice", age: 25 };
logName(obj); // ✅ 合法（obj 是 { name: string } 的子类型）

# Awaited<T[P]>

Awaited<T[P]> 是 TypeScript 中用于递归解包 Promise 类型的工具类型

type User = {
  id: Promise<number>;
  name: Promise<string>;
};

type UnwrappedUser = {
  id: Awaited<User["id"]>; // number
  name: Awaited<User["name"]>; // string
};

enum DirectionNumber {
  /** 上：1 */
  Up = 1,
  /** 下：2 */
  Down = 2,
  /** 左：3 */
  Left = 3,
  /** 右 */
  Right = 4,
}

enum DirectionString {
  /** 上：up */
  Up = "up",
  /** 下：down */
  Down = "down",
  /** 左：left */
  Left = "left",
  /** 右：right */
  Right = "right",
}

type DirectionNumberValue = `${DirectionNumber}`;
// "1" | "2" | "3" | "4"

// 或
type DirectionNumberValue = typeof DirectionNumber[keyof typeof DirectionNumber];
// 指向 DirectionNumber, 不推荐

# 联合类型部分特性

联合类型的所有子类型中均存在且必填，则该属性在联合类型中才是整体必填的 若属性在任一子类型中不存在或为可选，则该属性在整个联合类型中 ‌ 非必填 ‌ 直接访问联合类型对象的属性时，只能访问所有子类型 ‌ 共有的属性 ‌（无论是否必填）
